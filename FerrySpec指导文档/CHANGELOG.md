## v1.1.0 - 2026-06-10

### 新增：双 Git 开发范式

在 Skill 工程实践中，进一步明确 AI 协作开发中的安全边界：

- 代码仓库负责 `reality`：真实代码、测试、运行产物和部署配置。
- Skill 仓库负责 `blueprint / .ferry`：判断规则、PRD、架构、计划、todo、复盘和工具。
- 同一项目可以由两个 Git 仓库共同管理，分别保护现实实现和意识规则。
- 该范式用于防止 AI 修改代码时污染规则，或整理规则时误伤代码。
